#  📊Store Sales Analysis Dashboard (Microsoft Excel)

An interactive sales analytics dashboard built in Microsoft Excel using Pivot Tables, Charts, KPIs, and Slicers to analyze annual store performance.


## 📌 Project Overview

This project transforms raw retail sales data into an interactive dashboard that helps analyze:

- Monthly Sales Trends
- Order vs Sales Performance
- Sales by Gender
- Age Group Analysis
- Order Status
- Top Performing States
- Sales Channel Distribution
- Category Filters
- Monthly Filtering using Slicers

The dashboard enables quick business insights for better decision-making.

## 📊 Dashboard Insights

### Monthly Sales

- Sales peaked during March.
- Stable sales throughout the year.
- Highest order volume observed in Q1.

### Gender Analysis

- Women contributed approximately **64%** of total sales.
- Men contributed approximately **36%**.

### Order Status

- Delivered Orders: **92%**
- Cancelled Orders: **3%**
- Returned Orders: **3%**
- Refunded Orders: **2%**

### Top States

Top performing states include:

- Maharashtra
- Karnataka
- Uttar Pradesh
- Telangana
- Tamil Nadu

### Sales Channels

Orders were received through:

- Amazon
- Myntra
- Flipkart
- Ajio
- Meesho
- Nalli
- Others
